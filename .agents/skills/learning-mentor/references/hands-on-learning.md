# 사용자가 요청한 경우의 선택 실습

기본 학습은 [대화와 자기 설명](dialogue-learning.md)이다. 이 문서는 사용자가 코드 작성·실행 실습을 명시적으로 요청했을 때만 참고한다. 기술적 깊이를 원한다는 말만으로 실습을 원한다고 추정하지 않는다. 실습을 선택한 경우의 목표는 실제 코드의 동작 원리를 이해하고 작은 변형을 직접 다룰 수 있게 하는 것이다.

## 한 수업의 구성

- **얻을 능력:** 지금 다루는 기능에서 기술 목표 하나와 확인할 결과를 정한다. 기능 소개에 그치지 않고 요청 매핑, 상태 관리, 저장 경계 등 구체적인 원리를 선택한다. 필요한 업무 규칙을 그 원리와 연결한다.
- **원리와 시연:** 필요한 개념·문법을 먼저 설명하고, 실제 코드에서 한 입력값이 인자·객체·응답으로 변하는 과정을 보여 준다. 배운 적 없는 용어의 정의만 연속해서 묻지 않는다.
- **읽기와 추적:** 짧은 실제 코드 조각과 관련 파일·메서드를 제시한다. 학습자가 값·호출 순서·결과를 예상하고 추적하게 한다. 코드 전체를 길게 붙이고 스스로 이해해 오도록 맡기지 않는다.
- **작은 구현:** 실행 골격과 예시를 제공하고 학습자가 작성·수정할 핵심 부분을 명확히 한다. 한 번에 한 과제를 제시하며 학습자의 시도·코드를 기다린다. 사용자 요청 없이 정답 구현까지 먼저 완성하지 않는다.
- **실험:** 예상 → 실행·관찰 → 차이의 원인을 비교한다. 입력·조건을 하나 바꾸거나 실패를 재현하고 배운 원리와 연결한다. 실제 실행이 불가능하면 예상과 미실행 이유를 기록하고 결과를 만들어 내지 않는다.
- **변형과 도움 줄이기:** 유사한 과제에서 개념 힌트 → 부분 예시 → 적은 힌트 순으로 조정한다. 사용자가 어느 부분을 독립적으로 수행했는지 남긴다. 해설을 명시적으로 요청하면 보여 주고 이후 다른 조건으로 이해를 확인한다.

이론 학습만 원하거나 실행 환경이 없으면 코드 추적·출력 예측·설계 비교로 조정한다. 실습 참여를 강요하거나 의도하지 않은 고난도 문제로 진행을 막지 않는다.

## 실습 공간과 원본 프로젝트

- 원본 프로젝트는 계속 읽기 전용이다. 원본의 테스트·빌드·실행·환경 설정은 수행하지 않는다.
- 독립 실습은 학습 작업공간의 `labs/<project-id>/<topic>/`에 둔다. 공통 개념은 `labs/concepts/<topic>/`를 사용한다. 해당 실습의 작은 프로그램·테스트는 실행할 수 있다. 경로와 심볼릭 링크의 실제 대상이 학습 작업공간 안에 있는지 확인한다.
- 원본에서 필요한 최소 코드·규칙만 참고하고 학습용 입력·DB·실행 설정을 별도로 둔다. 원본의 인증정보·실제 고객 데이터·실행 환경을 복사하거나 연결하지 않는다.
- 단순 메모리 예제로 실제 DB 트랜잭션이나 Spring 프록시 동작을 검증했다고 표현하지 않는다. 실습이 보존한 원리, 단순화한 부분, 실제 프로젝트에서 확인할 부분을 구분한다.
- 원본을 바꿔야 하는 실험은 실행 계획으로 남긴다. 제품 개발 전달에는 기존 이해도·명시적 승인 gate를 그대로 적용한다.

## 평가와 기록

다음 근거를 조합해 학습을 확인한다.

- 학습자가 직접 추적한 값·호출·결과와 그 이유
- 학습자가 작성한 핵심 코드와 유지해야 할 업무 조건
- 실행 전 예상, 관찰한 결과, 예상과 달랐던 이유
- 조건을 바꾼 과제에서 독립적으로 해결한 부분과 필요한 도움

멘토가 작성한 코드나 자동 테스트 성공만으로 학습자 이해를 통과시키지 않는다. 기술·업무·코드 영역의 실제 근거를 세션에 남기고, 제품 전달용 기록의 `answer`, `evidence`, `reason`에는 해당 설명·과제·관찰 위치를 연결한다. 평가·승인은 검증기가 자동 부여하지 않는다.

실습 파일은 보관함 밖에 있으므로 노트에서 `file:` 링크와 학습 작업공간 기준 경로·재현 명령을 적는다. 관련 개념·프로젝트 적용·세션은 보관함 내부 링크로 연결하고 Canvas도 갱신한다. 원본 소스 근거용 `notes.py` 입력의 `sources`에 실습 폴더를 원본 프로젝트처럼 등록하지 않는다.

참고한 구성: [PRIMM 원문](https://kclpure.kcl.ac.uk/ws/portalfiles/portal/79583213/version_pure_primm_1.pdf)의 예측·실행·분석·수정·제작. 이 지침은 사용자의 현재 프로젝트 학습에 맞춘 적용이며 해당 연구가 성인 프로젝트 학습의 효과를 직접 검증했다고 주장하지 않는다.
