# 2026-11-16 — 독립 학습 시스템 설치와 검증

[학습 홈](../index.md) · [첫 학습 질문](markestream/client-company-creation.md)

## 사용자와 합의한 범위

기존 개발 에이전트와 병합하지 않고 `markestream-learning`에 독립된 규칙·스킬·학습 보관함을 만든다. 기존 마케스트림의 코드와 AGENTS.md는 유지한다. 사용자는 이 분리안을 “응응”으로 승인했다. 이 승인은 학습 시스템 설치에 한정되며 제품 구현이나 이해도 통과 승인이 아니다.

## 만든 구성

- 독립 AGENTS.md와 원본 프로젝트 상대 경로 설정
- 질문·교육·재평가·승인·개발 전달을 맡는 `learning-mentor` 스킬
- 실제 코드·업무·설계 근거를 연결하는 `obsidian-notes` 스킬
- 생성 영역만 갱신하는 노트 도구, 범위·평가·승인·코드 지문을 확인하는 전달서 점검 도구
- 광고주 회사 생성 예제 노트, 미응답 진단 기록, 개념·세션·개발 전달서 양식

원본 학습 자료는 참고 자료로 읽었고, 새 기록은 별도 보관함에만 작성했다. 두 스킬은 이 작업공간의 `.agents/skills`에만 설치했다. 전역 에이전트·스킬 설정과 기존 개발 프로젝트 규칙은 바꾸지 않았다.

## 실행한 검증

| 점검 | 관찰 결과 |
| --- | --- |
| Skill Creator의 `quick_validate.py` | 두 SKILL.md 모두 통과 |
| 스킬 UI 메타데이터 | 두 파일의 이름·설명·호출 문구 확인 |
| `python3 -B -m unittest discover -s tests -v` | 14개 합성 사례 통과 |
| 실제 예제 노트 생성과 `notes.py check` | 노트 1개, 코드·설계 근거 9개 확인, 오류 없음 |
| 실제 첫 학습 기록 점검 | `eligible: false`, 종료 코드 2. 미응답·범위 미정·미승인 상태이므로 기대한 결과 |
| 원본 프로젝트 보존 | 추적 파일 937개의 SHA-256 동일, Git status와 HEAD 동일 |

스킬 형식 검증용 PyYAML은 `/tmp`의 별도 가상환경에만 설치했다. 학습 도구는 Python 표준 라이브러리만 사용하며 원본 프로젝트의 의존성은 바꾸지 않았다.

## 합성 사례에서 확인한 동작

| 입력·상황 | 관찰 |
| --- | --- |
| 답변 없음 | 전달 불가 |
| passed 표시만 있고 답변 근거 없음 | 전달 불가 |
| 세 영역 통과, 사용자 승인 없음 | 전달 불가 |
| 평가 완료 전의 승인 | 전달 불가 |
| 승인 후 범위 변경 | 전달 불가 |
| 평가 근거 코드 변경 | 전달 불가 |
| 모든 기록 조건을 충족한 합성 사례 | 전달 자격 표시, 원본 파일·기록은 변경하지 않음 |
| 노트 재생성 | 생성 영역만 갱신, 사용자 필기와 추가 속성 보존 |
| 생성 영역 없는 기존 파일 | 덮어쓰기 거절 |
| 출력 경로 우회 또는 원본으로 향하는 심볼릭 링크 | 원본 쓰기 거절 |
| 없는 코드 심볼 또는 원본 밖 참조 | 노트 생성 거절 |
| 소스 변경 후 점검 | 변경 감지 |
| 노트 입력으로 학습 통과 상태 지정 | 입력 거절 |

이 결과는 도구의 데이터 처리 검증이다. 실제 사용자 이해도를 평가했거나 새 Codex 채팅에서 모델 행동을 검증한 결과가 아니다. 기록의 의미와 승인 진위는 실제 대화와 대조해야 한다. 기존 개발 에이전트의 구현을 강제 차단하는 기능은 설치하지 않았다.

## 현재 남은 상태

실제 첫 학습은 아직 시작하지 않았다. 세 영역은 모두 pending이며 제품 구현 범위와 승인은 없다. 원본 애플리케이션 빌드·테스트·DB·인프라는 이번 설치에서 실행하지 않았다.

Codex의 작업 프로젝트를 `markestream-learning`으로 열고 첫 진단 질문부터 시작한다. Obsidian은 `notes` 폴더를 보관함으로 열어 사용한다. 이 설치에서는 Obsidian 앱을 직접 열거나 사용자의 앱 설정을 바꾸지 않았다.

## 공통 작업공간 전환

이 문서의 `markestream-learning`과 14개 테스트 결과는 최초 설치 당시 기록이다. 이후 승인된 공통 학습 전환으로 현재 작업공간은 `agent-learning`이며 실행법은 [현재 안내](../learning-workflow.md)를 따른다. 최초 단일 프로젝트 설정은 `records/setup/source-project-original.json`에 보존했다.
