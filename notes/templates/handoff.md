# 개발 전달서 양식 — 실행 승인 아님

이 파일은 양식이다. 모든 조건이 충족될 때만 별도 `handoffs/<project-id>/<task-id>.md`를 만든다. 아래에 실제 사용자 근거가 없으면 구현 요청으로 사용하지 않는다.

## 사용자가 승인한 범위

프로젝트 ID·절대 경로, 목표, 수정 가능 파일·영역, 제외 항목, 사용자 승인 원문·시각·대화 출처를 적는다.

## 학습 통과 근거

기술·비즈니스·코드 영역별 질문, 실제 답변과 평가 이유를 관련 세션에 연결한다.

## 코드와 업무 규칙

원본 코드 경로·심볼·확인 해시, 권한·회사 범위·상태 전이·호환성 요구를 적는다. 관련 PRD·ADR과 유지할 테스트를 연결한다.

## 구현과 검증 계획

변경할 책임, 확인할 성공·실패·권한·동시성 시나리오를 적는다. 실행하지 않은 테스트는 계획으로 표시한다.

## 전달 전 점검

평가 기록 경로, `check_handoff.py` 결과, 소스 변경 여부와 검토 시각을 기록한다. 기존 개발 에이전트는 자신의 규칙과 현재 코드를 확인하며, 이 문서의 권한 범위를 임의로 확대하지 않는다.
